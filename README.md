# Ed Jude — Food & Hospitality Portfolio

Static HTML, CSS and JavaScript portfolio. Hospitality samples are concept projects.
The enquiry form is a demo and does not send or store submissions.

## Publish with GitHub Pages
1. Create a public repository named ed-jude-portfolio.
2. Extract this ZIP and upload the files directly to the repository root (index.html must be at the root).
3. Commit the files to the main branch.
4. Open Settings > Pages. Under Build and deployment, select Deploy from a branch.
5. Select main and / (root), then Save.
6. Open the published URL shown in Settings > Pages after deployment finishes.

Replace the portfolio contact text with your preferred contact details before sharing.
